# Template OS

**Um workspace de trabalho para o Claude Code, que aprende quem você é e passa a
produzir no seu nome.**

</div>

---

## Como começa

**1. Clone este repositório** na pasta onde você trabalha:

```
git clone https://github.com/eumateusalex/Template-OS.git
```

**2. Abra a pasta `Template-OS` no Claude Code.**

**3. Digite `/instalar`.**

Daí em diante, o próprio workspace conduz: uma entrevista curta para aprender quem
você é, o que falta instalar na sua máquina, o que ele faz pelo seu negócio e o
seu primeiro passo.

> Para clonar e começar, você precisa do [Git](https://git-scm.com), do
> [Node.js](https://nodejs.org) 22.7 ou superior e do
> [Claude Code](https://claude.com/claude-code). O resto, o `/instalar` confere
> e diz como instalar.
