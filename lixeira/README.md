# lixeira/

Área de quarentena da `/sanitizacao` para o que **não está no git**. O que o
git rastreia sai com `git rm`, e o git é a volta. O resto vem primeiro para cá,
registrado no `_manifesto.md`
(origem, data, motivo), e só é apagado em definitivo com aprovação
explícita do usuário — respeitando quarentena de 14 dias.

- Para restaurar um item: consulte a `Origem` no `_manifesto.md`.
- Para esvaziar: peça ao Claude ("esvaziar lixeira") — ele lista o que
  será apagado e pede confirmação antes.

O conteúdo desta pasta não é versionado (só este README e o `_manifesto.md`).
