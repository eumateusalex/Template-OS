# Console de agentes de voz

**Console de agentes de voz: chamada, diagnóstico, testes e versões.** **[CONFIRMADO]** pelo logo.

| Campo | Valor |
|---|---|
| Setor | operação de agente de voz de atendimento: histórico de chamadas, diagnóstico, laboratório de teste, versões, criação |
| Para quem | o time de IA do atendimento |
| Tema | escuro (azul-noite) |
| Plataforma | web |
| Acento | azul-elétrico no logo e botões; vermelho e verde no diff [OBSERVADO] |

## O que a ficha ensina

- **Transforme a falha em teste**: do diagnóstico "Refund workflow failed" sai "Create test case" com "Block deploy if this test fails".
- **Trate a versão do agente como código**: diff das instruções em vermelho e verde e as métricas da versão base contra a nova.
- **No teste, mostre esperado x real e a causa provável** ("Likely cause").
