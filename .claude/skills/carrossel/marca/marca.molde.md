# A marca visual

O que este arquivo é: o que é visual e de uso da peça e não cabe no `tokens.css`: a logo e onde ela assina, a voz de narração do vídeo e as recusas visuais. Toda peça lê este arquivo antes de montar. Este é o molde: a skill copia ele pra `marca/marca.md` na primeira vez, e é o `marca.md` que `/carrossel configurar` preenche (ou você, à mão). O `marca.md` é seu e se versiona com o workspace.

Se a marca está configurada quem diz é o `tokens.css` (a linha `ESTADO: nao-configurado` some dele na entrevista), não este arquivo.
