# Projeto

Criado pelo `/novo-projeto`, na trilha app: Next, Tailwind, shadcn e o portão
da fábrica. A marca mora em `src/styles/`; a parte conferida, em `fundacao/`.

sem spec declarado: projeto recém-criado, antes da primeira feature. Quando a
primeira nascer (`/fabrica`), o rastro dela vai em `specs/` e esta linha sai.

## Comandos

- `npm run dev` · o site em desenvolvimento
- `npm run portao` · tudo que precisa passar antes de um commit
- `npm run testar` e `npm run tela` · os testes de unidade e os de navegador

A `/vitrine` mostra os componentes nos dois registros, claro e escuro. Ela não
entra no sitemap e não é indexada.
