# A lista de saída (F6)

> No fim de uma onda sem renovação, ou do contrato. **Só fecha com todo item
> marcado**; o que faltar fica com a data e o motivo no `ESTADO.md`.

- [ ] **Revogar cada acesso**: em cada linha do `ACESSOS.md`, a data em "revogado em" (quem revoga é o cliente, na ferramenta; o operador confere que caiu)
- [ ] **Entregar a documentação**: cada oportunidade implementada com a página "como funciona / o que fazer quando quebrar" em `saidas/`
- [ ] **O treinamento feito**: o cliente executou sozinho cada entrega uma vez, observado, com a data
- [ ] **O último relatório** com os indicadores contra a linha de base (`KPIS.md`)
- [ ] **Marcar a data de apagar `dados/`**: 90 dias depois do fim, no `ESTADO.md`
- [ ] **No dia, apagar em todas as cópias**: `dados/` direto, **sem passar pela `lixeira/` do workspace** (a quarentena de 14 dias não vale para dado de cliente); a lixeira do sistema; e a lixeira do serviço de nuvem na web, se a pasta sincroniza. Depois, mandar o comprovante ao cliente: a data, a lista dos arquivos e de onde saíram
- [ ] **Pedir o caso por escrito**: mensagem pronta para você enviar, só se houver resultado medido; o texto do caso vai para o cliente aprovar
- [ ] **A decisão de continuar**: renova, pausa ou encerra, registrada no `DECISOES.md`
